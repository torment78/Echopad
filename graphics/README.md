# EchoPad graphics

Matching waveform artwork for the ElkaSoft audio-software family, with a brighter cyan, magenta, violet, amber and lime palette. Both images use the existing EchoPad pad-icon design.

| File | Dimensions | Bytes | Use |
| --- | --- | ---: | --- |

| [Vertical PNG](echopad-vertical.png) | 941 × 1672 | 1,838,230 | Portrait artwork |
| [Horizontal preview JPEG](echopad-preview.jpg) | 1774 × 887 | 373,410 | Preview/upload under 1 MB |
| [Icon reference](references/echopad-icon.png) | 1024 × 1024 | 658,653 | Existing ICO's embedded PNG, extracted unchanged |

![EchoPad horizontal artwork](echopad-preview.jpg)

The PNGs were generated with the built-in image-generation tool; [the exact prompts](PROMPTS.md) document the references and composition. The preview uses JPEG quality 92 with the original dimensions. The application and installer icons are unchanged. This directory ships with the release ZIP and installer payload.
